# Documentação Histórica

**Classificação documental:** Histórico  
**Status:** Histórico  
**Autoridade/Escopo:** preservação da evolução; sem autoridade vigente

Esta pasta contém versões arquivadas de documentos substituídos.

Os arquivos aqui presentes possuem finalidade exclusivamente histórica
e não representam a documentação vigente do projeto.

Ao analisar a arquitetura atual, utilizar o índice e os documentos classificados
como vigentes em [`docs/README.md`](../README.md).

A [exportação histórica do contexto de planejamento](contexto_do_planejamento_do_projeto_backend.md)
preserva o material consolidado no passo 5 da seção 17.

Os [exemplos didáticos iniciais](didatico/README.md) preservam exercícios de
autoload e PHPUnit que deixaram de fazer parte da aplicação ativa.

A pasta `docs/historico/` deve ser consultada apenas para:

- auditoria de decisões;
- comparação de evolução;
- estudo do processo de refatoração documental.
